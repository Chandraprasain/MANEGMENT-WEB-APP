# Architecture Overview

- **Frontend**: React 19 + TypeScript + Tailwind CSS v4 SPA bundled by Vite + `vite-plugin-pwa`. Features V4.0–V4.1 modules across `Learning & Exams`, `Payments & Finance`, `Automation & Agents`, and `Safeguarding & Hub`.
- **Offline Layer**: IndexedDB (`shikshyaplus_offline_v1`) provides `query_cache` for cached GET fallbacks and `sync_queue` for offline POST/PATCH mutations, replayed automatically on `online` events. Payment checkout and verification routes require online server-side finality.
- **Backend**: Express 4 + `ws` (`noServer: true` on `/ws`) running on port `3000` (`server.ts`), mounting `vite.middlewares` in development (with `/@vite/client` no-WS shim to prevent iframe reload loops) and serving `dist/` in production.
- **Database**: Node 22 built-in `node:sqlite` (`DatabaseSync` in `server/db.ts` + V4 schema/seed engine in `server/dbV4Migrations.ts`) with `PRAGMA foreign_keys = ON` and WAL mode. Equivalent PostgreSQL/Supabase migration schemas with Row-Level Security are included in `supabase/migrations/001_initial_schema.sql` and `supabase/migrations/002_v4_global_education_and_finance_hub.sql`.
- **AI Gateway & Automation Engine**: Server-side `@google/genai` integration (`gemini-4-hydrogen`) in `server/aiGateway.ts` supporting role-scoped AI agents (`PRINCIPAL_OPS`, `TEACHER_PEDAGOGY`, `STUDENT_TUTOR`, `PARENT_GUIDE`, `TECH_SUPPORT`) with draft human-approval gates and AI governance audit logging. `server/services/automationEngine.ts` runs loop-guarded (max depth 3), idempotent event workflows wired to attendance and exam publishing.
- **Finance & Payment Adapters**: `server/services/encryption.ts` provides AES-256-GCM credential encryption and HMAC payload signing (`Open Badges 3.0`, webhook signatures). `server/services/paymentAdapters.ts` provides Nepal payment gateway adapters (`ESEWA`, `KHALTI`, `CONNECTIPS`, `DIRECT_BANK`) and strict balanced double-entry accounting ledger posting.
